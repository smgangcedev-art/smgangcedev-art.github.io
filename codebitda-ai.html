코드빚다 AI Mac 설치 방법

Python 3.11·TensorFlow·NumPy·Matplotlib이 앱에 포함되어 있습니다. Python이나 Anaconda를 별도로 설치할 필요가 없습니다.

  1. 위의 AI Mac DMG를 다운로드하고 엽니다.
  2. 코드빚다-AI.app을 DMG 안의 Applications(응용 프로그램) 폴더로 드래그합니다.
  3. 복사가 끝나면 Finder의 응용 프로그램 폴더에서 코드빚다-AI를 실행합니다. 보안 경고가 나오면 아래 안내를 확인하세요.
  4. 첫 코드 실행 때는 Python·TensorFlow 준비에 시간이 걸릴 수 있으니 잠시 기다려 주세요.
  5. 앱이 열리면 담당 교강사의 안내에 따라 과제 시작 또는 시험 응시를 선택합니다. 설치 디스크는 추출해도 됩니다.

학생은 Google 로그인 없이 과제·시험에 참여합니다. 교수·조교·마스터는 앱에서 Google 로그인을 사용합니다.

Mac 2.0.2 수업 진행 안내

교수자는 시험 시작 전에 해당 시험의 XLSX 또는 UTF-8 CSV 명단을 등록하세요. 학번은 앞자리 0을 포함한 텍스트로 저장합니다. 소속 조교도 같은 명단을 조회하며, 교체는 교수자만 할 수 있습니다. 학생은 학번으로 참여하므로 이름 표기가 달라도 차단하지 않습니다.

최종 제출하면 답안과 실행 결과가 고정됩니다. 전송 실패 시 대기 상태를 유지하고 같은 내용을 재전송하므로 앱을 열어 두세요. 서버 저장 후에도 교수자 또는 소속 조교의 제출 확인을 기다린 다음 활성화된 종료 버튼을 누릅니다.

교수자·소속 조교는 학생 현황 조회, 백업 복구 승인, 개별·전체 과제 전환을 할 수 있습니다. 이미 제출한 답안은 다시 열리지 않으며 각 앱의 계정 권한과 학생 데이터는 분리됩니다.

2.0.1부터 자동 업데이트를 지원합니다.

2.0.0 사용자는 이번 2.0.2를 한 번 직접 설치하세요. 2.0.1 사용자는 메인화면에서 이번 업데이트를 자동으로 내려받습니다.

작업을 저장·제출한 뒤 메인화면의 업데이트 및 재시작 / Update & restart을 누르면 앱을 교체하고 다시 엽니다. 시험·과제·출제 중에는 자동으로 재시작하지 않습니다.

업데이트 파일의 전자서명과 무결성을 확인하며, 새 앱이 정상 시작하지 못하면 이전 앱으로 복구를 시도합니다. 쓰기 권한이나 macOS 보안 확인 때문에 자동 설치가 실패하면 위 DMG로 직접 설치하세요.

첫 실행 시 보안 경고가 표시될 수 있습니다.

현재 Mac 2.0.2는 임시 서명 배포본이며 Apple 공증은 포함되지 않습니다. 이 홈페이지에서 받은 코드빚다-AI 앱인지 확인하고 아래 안내를 따라 주세요.

개발자를 확인할 수 없거나 Apple에서 확인할 수 없다고 나와요.

코드빚다-AI 실행을 한 번 시도한 뒤 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기를 확인하세요. 열려는 앱 이름이 코드빚다-AI인지 확인합니다. 학교에서 관리하는 Mac에서 허용할 수 없다면 담당 관리자에게 문의하세요.

Apple의 Mac 앱 열기 안내 ↗

앱이 손상되었다는 메시지가 나와요.

다운로드와 앱 복사가 끝났는지 확인하고, 위의 AI Mac DMG를 다시 다운로드하여 설치해 주세요. 그래도 같은 메시지가 나오면 오류 화면과 macOS 버전을 담당 교강사에게 전달해 주세요.

교수자는 Google 계정으로 가입하고 승인 후 자신의 Drive를 연결합니다. 초대한 조교와 문제를 수정하고 채점하며, 학생은 Google 로그인 없이 답안을 제출합니다. 제출 파일과 제출학생명단은 연결된 교수자의 폴더에 저장됩니다.

Python·TensorFlow가 포함되어 있습니다.

별도 설치 없이 Python 3.11, TensorFlow 2.15.1, NumPy, Matplotlib로 실습합니다. Windows CPU 환경을 사용하며, 첫 실행은 라이브러리 준비에 시간이 걸릴 수 있습니다. 실행 속도는 컴퓨터 사양에 따라 달라집니다.

TensorFlow는 Apache License 2.0으로 제공됩니다. Python 및 관련 라이브러리는 각각의 라이선스를 따르며, 배포 앱에 원문 고지가 포함되어 있습니다. 코드빚다는 Google 또는 TensorFlow 프로젝트의 공식 제품이 아닙니다.
