Mac 설치 안내

  1. 위에서 필요한 DMG 파일을 다운로드하고 엽니다.
  2. Java·AI는 앱을 Applications(응용 프로그램) 폴더로 옮긴 뒤 실행합니다. C++은 DMG 안의 앱을 실행하고 ‘설치 시작’을 눌러 ‘코드빚다 C++ 환경설정’을 진행합니다.
  3. C++ 실행 도구가 없으면 Apple Command Line Tools 설치 안내를 따릅니다. 전체 Xcode 앱은 필요하지 않습니다.
개발자를 확인할 수 없다는 보안 경고가 나와요.

이 홈페이지에서 받은 앱인지 확인한 뒤 실행을 한 번 시도하고, 시스템 설정 → 개인정보 보호 및 보안에서 ‘그래도 열기’를 확인하세요. 학교에서 관리하는 Mac이라면 담당 관리자에게 문의하세요.
