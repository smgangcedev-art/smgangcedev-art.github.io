How to install Codebitda C++ on Mac

The full Xcode app is not required. C++ compilation uses Apple Command Line Tools. If the tools are already available, you can skip installing them.

These instructions are in English. App buttons may still appear in Korean; the original labels are shown below where needed.

  1. Download the C++ Mac DMG above and open it.
  2. Open 코드빚다-C++.app inside the DMG. If a security warning appears, see the guidance below.
  3. In 코드빚다 C++ 환경설정 (C++ Setup), click 설치 시작 (Start installation) to install the app in Applications.
  4. If the tools are missing, click Apple 실행 도구 설치 (Install Apple tools) and complete the Apple installer. An internet connection may be required.
  5. Click 설치 완료 여부 확인 (Check installation). After the C++ check passes, click 앱 실행 (Open app).
  6. From then on, open 코드빚다-C++ from Applications. You can eject the installation disk.

Students can take assignments and exams without signing in to Google. Instructors, teaching assistants, and the master administrator use Google sign-in in the app.

A security warning may appear the first time you open the app.

Mac 2.0.0 is ad-hoc signed and is not notarized by Apple. Make sure you downloaded 코드빚다-C++ from this website, then follow the instructions below.

macOS says the developer cannot be verified or Apple cannot verify this app.

Try opening 코드빚다-C++ once, then check System Settings → Privacy & Security → Open Anyway. Make sure the app name matches 코드빚다-C++. On a school-managed Mac, contact your administrator if you cannot allow it.

Apple’s guide to opening Mac apps ↗

macOS says the app is damaged.

Make sure the download and app copy are complete. Download the C++ Mac DMG above again and reinstall. If the message persists, send a screenshot of the error and your macOS version to your instructor.
