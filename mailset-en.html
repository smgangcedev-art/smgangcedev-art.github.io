How to fill in the list

  • Put column headings in the first row and one person per row below. Keep only one recipient-list worksheet in each file.
  • The ID and name columns are required. A valid email address is also needed to send mail. Student, customer or member IDs can replace the reference ID. Enter IDs with leading zeros as text in Excel.
  • The topic can be a course, service or event name. Replace billing amounts and due dates with real information. Use YYYY-MM-DD for dates and YYYY-MM for billing months.
  • If there are no attachments, leave both the Attachments column and the automatic matching folder empty. For automatic matching, leave the column empty and choose a folder and an ID or name matching rule in the app. Example: C001_notice.pdf.
  • For direct selection, enter full paths in the Attachments column. Separate multiple files with semicolons (;), for example C:\MailSetFiles\notice.pdf;C:\MailSetFiles\invoice.pdf. Relative paths use the selected matching folder, or the list file's location if no folder is selected.
  • Save CSV files as UTF-8. Values containing commas must be quoted, so Excel's CSV save feature is convenient.

The multilingual version also recognizes English headings such as ID, Name, Email, Topic, Amount, Due Date, Billing Month, Payment Info and Attachments. Check recipients and matched files in the app before sending.

01 / IMPORT

Use your Excel list

Import XLS, XLSX and CSV files and review recipients. Add people not in the list or exclude unnecessary entries.

02 / ATTACH

Individual attachments

Link files by reference ID, student ID or name. Multiple attachments and copying and pasting paths are supported.

03 / COMPOSE

Messages for each recipient

Edit the subject and body and fill in names, topics and other fields automatically. Sender and reply-to addresses can be set separately.

04 / SELECT

Select recipients with checkboxes

Send to one person, several selected people or everyone. Send one test to your own email first to check the content.

05 / SCHEDULE

Schedule once or monthly

Schedule messages for a specified time or the same date each month. Automatic updates to billing months and due dates are optional.

06 / TRACK

Progress and history

Check progress and completion notifications. Save mail settings and, if you choose, remember the app password encrypted for this Windows account.

Before you start

You need your own mail account with SMTP support. Depending on the account, Gmail may require 2-Step Verification and an app password. The PC and app must be running and online at the scheduled time. Your mail provider's sending limits apply.

Scheduled copies of recipients, message bodies and attachments do not change when you edit the originals. Recurring billing date options update message text, not dates or amounts inside attachments.
