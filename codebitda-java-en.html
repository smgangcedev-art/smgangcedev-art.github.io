How to install Codebitda Java on Mac

The JDK is included in the app. You do not need to install Java or a JDK separately, or configure paths.

These instructions are in English. App buttons may still appear in Korean; the original labels are shown below where needed.

  1. Download the Java Mac DMG above and open it.
  2. Drag 코드빚다-JAVA.app to the Applications folder inside the DMG.
  3. When copying is complete, open 코드빚다-JAVA from Applications in Finder. If a security warning appears, see the guidance below.
  4. Once the app opens, select the assignment or exam option as instructed by your instructor. You can eject the installation disk.

Students can take assignments and exams without signing in to Google. Instructors, teaching assistants, and the master administrator use Google sign-in in the app.

A security warning may appear the first time you open the app.

Mac 2.0.0 is ad-hoc signed and is not notarized by Apple. Make sure you downloaded 코드빚다-JAVA from this website, then follow the instructions below.

macOS says the developer cannot be verified or Apple cannot verify this app.

Try opening 코드빚다-JAVA once, then check System Settings → Privacy & Security → Open Anyway. Make sure the app name matches 코드빚다-JAVA. On a school-managed Mac, contact your administrator if you cannot allow it.

Apple’s guide to opening Mac apps ↗

macOS says the app is damaged.

Make sure the download and app copy are complete. Download the Java Mac DMG above again and reinstall. If the message persists, send a screenshot of the error and your macOS version to your instructor.
