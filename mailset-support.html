MailSet 사용 안내

출시 준비 버전을 기준으로 작성한 안내입니다. 기능과 화면은 정식 출시 시 달라질 수 있습니다.

1. 용도와 명단 준비

교육, 비즈니스, 개인 업무, 단체, 청구, 직접 작성 중 용도를 선택하세요. XLS·XLSX·CSV 명단을 불러온 뒤 이름·이메일·관리번호·안내항목을 확인합니다. 학번과 교과목 정보가 있는 교육용 명단도 사용할 수 있습니다.

명단에 없는 수신자는 추가하고 보내지 않을 수신자는 제외합니다. 이메일 주소는 발송 전에 수정할 수 있습니다.

2. 첨부파일 확인

파일 이름에 관리번호·학번 또는 이름을 넣어 자동 매칭 폴더에서 연결하거나, 수신자별로 파일을 직접 지정합니다. 한 명에게 여러 파일을 첨부할 수 있습니다. 동명이인이나 중복 항목은 개별 매칭 결과를 확인하세요.

3. 메일 계정 설정과 테스트

SMTP 서버·포트·보내는 주소와 인증 정보를 입력합니다. Gmail 앱 비밀번호는 Google 계정의 2단계 인증을 설정한 뒤 앱 비밀번호 화면에서 만들 수 있으며, 조직 정책이나 계정 설정에 따라 제공되지 않을 수 있습니다.

  • Google 앱 비밀번호 설정
  • Google 공식 앱 비밀번호 도움말

Gmail로 보내면서 학교·회사 주소로 답장을 받으려면 답장받을 주소(Reply-To)에 해당 주소를 입력합니다. 발신 주소 자체는 Gmail로 표시됩니다. 앱의 세 번째 탭에서도 앱 비밀번호 발급 방법을 확인할 수 있습니다.

제목·본문과 미리보기를 확인한 뒤 ‘내 메일로 테스트 (1통)’를 실행하세요. 이 기능은 실제 메일 한 통을 보내므로 먼저 계정과 첨부파일을 확인해야 합니다.

4. 선택·전체 발송

체크박스로 수신자를 선택합니다. 한 명만 체크하면 단일 발송, 여러 명을 체크하면 선택 발송을 할 수 있습니다. 전체 선택·선택 해제로 대상을 조정하고, 전체 발송 버튼은 따로 사용합니다. 완료 표시의 성공은 SMTP 서버 접수 기준이며 받은편지함 도착이나 열람을 보장하지 않습니다.

5. 예약·반복 청구

네 번째 탭에서 1회 예약이나 매월 반복을 등록합니다. PC 현지 시간을 사용하며 PC·앱·인터넷 연결이 유지되어야 합니다. 앱이 꺼져 있거나 절전 상태이면 발송하지 않습니다. 5분 이상 지난 예약은 자동으로 몰아서 보내지 않으며, 상태를 확인해 직접 실행해야 합니다.

월말 날짜가 없는 달은 해당 달 말일을 사용합니다. 청구 날짜 자동 변경을 켜면 청구월과 납부기한을 발송 월에 맞춥니다. 금액·수신자·첨부파일은 등록한 내용 그대로이므로 변경이 필요하면 예약을 취소하고 새로 등록하세요. 중지·오류 건은 기록을 확인한 뒤 필요한 대상만 다시 준비하세요.
