개인정보처리방침

최종 수정일: 2026년 10월 15일 · Windows 무료판 1.0.0

codepretender는 Allset 무료판과 이 홈페이지의 데이터 처리 방식을 안내합니다. 기존 테스트 버전 이용자는 테스트 버전 데이터 처리 안내를 참고해 주세요.

1. 기기에 저장되는 기록

메모, 할 일, 일정, 기념일과 생년월일, 태그·해시태그, 시간표, 공정률 기록, 완료 기록 및 앱 설정은 사용자의 컴퓨터에 저장됩니다. 무료판은 회원가입 없이 사용하며 기본 기록을 개발자의 서버에 전송하지 않습니다.

2. 로컬 백업

백업에는 앱 기록과 백업 대상 설정, 생성 시각, 운영체제 및 기기 이름 등이 포함될 수 있습니다. 백업은 선택한 저장 위치에 남으며 사용자가 직접 선택한 동기화 폴더나 외부 저장장치에 사본이 남을 수 있습니다.

3. 외부 자료와 홈페이지

공휴일·음력 자료를 갱신할 때 GitHub에 게시된 자료를 요청할 수 있습니다. 요청에 메모나 일정 본문을 포함하지 않습니다. 홈페이지는 GitHub Pages로 제공되며 별도의 광고 추적·방문 분석 스크립트나 문의 입력 폼은 설치하지 않았습니다. 서비스 제공자는 요청 처리와 보안을 위해 접속 정보를 처리할 수 있습니다.

4. 보관과 삭제

  • 삭제한 기록은 휴지통과 기존 백업에 사본이 남을 수 있습니다. 휴지통은 최대 30일 보관 후 정리되며 영구 삭제할 수 있습니다.
  • 완전히 삭제하려면 로컬 앱 데이터와 백업 위치를 각각 확인하세요. 앱 삭제만으로 모든 사본이 삭제되지는 않습니다.
  • 개발자는 로컬 기록을 직접 열람하거나 삭제할 수 없습니다.

5. 이메일 문의

문의 이메일을 보내면 이메일 주소, 문의 내용 및 첨부 자료를 받습니다. 이 정보는 답변과 문제 해결에 사용합니다. 비밀번호나 전체 백업 파일은 보내지 마세요. 문의 자료 삭제는 같은 이메일로 요청할 수 있습니다.
