개인정보처리방침

최종 작성일: 2026년 10월 13일 · 출시 준비 버전

codepretender는 Allset의 데이터 처리 방식을 다음과 같이 안내합니다. 이 방침은 Allset 데스크톱 앱과 이 개발자 홈페이지에 적용됩니다. 출시 전 기능 또는 처리 방식이 변경되면 방침을 갱신합니다.

1. 기기에 저장되는 기록

메모, 할 일, 일정, 기념일과 생년월일, 태그·해시태그, 시간표, 공정률 기록, 완료 기록 및 앱 설정은 기본적으로 사용자의 컴퓨터에 저장됩니다. 앱의 로컬 백업이나 내보내기를 사용하면 해당 데이터의 사본이 선택한 저장 위치에도 남습니다. 기본 메모·일정 기능을 위해 별도의 codepretender 계정을 만들 필요는 없습니다.

2. 선택적 Google 연결

사용자가 Google 연결을 선택하면 계정 식별과 연결 상태 표시를 위해 Google 계정 이메일 및 이메일 확인 정보를 사용합니다. 백업·복원에는 Google Drive의 앱 전용 저장 공간 접근 권한(drive.appdata)을 사용합니다. 이 권한으로 사용자의 일반 Drive 파일 전체에 접근하지 않습니다.

백업에는 앱의 기록과 백업 대상 설정, 생성 시각, 운영체제 및 기기 이름 등의 정보가 포함될 수 있습니다. 파일은 사용자가 연결한 Google 계정의 앱 전용 공간에 전송되며 일반 Drive 파일 목록에는 보이지 않습니다. 자동 백업은 사용자가 켠 경우 동작합니다. 백업·복원은 여러 기기의 변경 내용을 실시간으로 병합하는 공동 편집 기능이 아닙니다.

앱은 Google 계정 비밀번호를 받거나 저장하지 않습니다. 인증은 Google 로그인 화면에서 진행되며, 연결 유지를 위한 인증 토큰은 운영체제의 보안 저장 기능으로 암호화하여 기기에 저장합니다. 보안 저장 기능을 사용할 수 없으면 연결 정보 저장을 진행하지 않습니다.

3. 전송과 외부 서비스

기본 메모·일정 기록을 codepretender의 별도 서버에 수집하지 않습니다. Google 백업 사용 시 데이터는 Google로 전송됩니다. 공휴일·음력 자료를 갱신할 때에는 GitHub에 게시된 자료를 요청하며, 이 요청에 사용자의 메모나 일정 본문을 포함하지 않습니다.

이 홈페이지는 GitHub Pages로 제공됩니다. 홈페이지에 별도의 광고 추적, 방문 분석 스크립트 또는 문의 입력 폼을 설치하지 않았습니다. 다만 GitHub 등 서비스 제공자는 요청 처리와 보안을 위해 IP 주소 등의 접속 정보를 자체 정책에 따라 처리할 수 있습니다. Google과 GitHub 등 해외 서비스 이용 시 데이터가 국외에서 처리될 수 있습니다.

4. 이용 목적과 제한

Google에서 받은 정보는 계정 연결 표시와 사용자가 요청한 백업·복원을 제공하는 목적으로만 사용합니다. Google 사용자 데이터를 판매하거나 광고 타기팅 또는 범용 AI 모델 학습에 사용하지 않습니다. Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용(Limited Use) 요건을 포함한 Google API Services User Data Policy를 준수합니다.

5. 보관, 삭제 및 연결 해제

  • 로컬 기록과 백업은 사용자의 기기 및 선택한 저장 위치에 보관됩니다. 앱에서 기록을 삭제하더라도 휴지통, 기존 백업 및 내보낸 파일에 사본이 남을 수 있습니다. 앱 휴지통은 최대 30일 보관 후 정리되며, 영구 삭제 기능으로 먼저 삭제할 수 있습니다.
  • Google 연결 해제는 기기의 연결 정보를 삭제하고 Google 권한 해제를 시도합니다. 기존 클라우드 백업 파일은 자동 삭제하지 않습니다.
  • Google 권한은 Google 계정의 연결 관리에서도 해제할 수 있습니다. 앱 전용 백업 데이터는 Google Drive 설정의 앱 관리에서 해당 앱의 숨겨진 앱 데이터 삭제 기능을 통해 정리할 수 있습니다.
  • 완전한 삭제를 원하면 로컬 앱 데이터, 로컬 백업, 내보낸 파일과 Google 백업을 각각 확인해야 합니다. 앱 삭제만으로 모든 사본이 삭제된다고 보장하지 않습니다.

6. 이메일 문의

문의 이메일을 보내면 이메일 주소, 문의 내용 및 사용자가 첨부한 자료를 받습니다. 이 정보는 문의 답변과 문제 해결을 위해 사용합니다. 비밀번호나 인증 토큰 등은 보내지 마세요. 문의 자료의 삭제를 원하면 같은 이메일로 요청할 수 있습니다. 앱의 로컬 기록이나 개인 Drive 백업은 개발자가 직접 열람·삭제할 수 없습니다.
