개인정보처리방침

최종 수정일: 2026년 10월 19일

codepretender는 Allset과 이 홈페이지의 데이터 처리 방식을 안내합니다. Microsoft Store 무료판 1.0.2는 로컬 기능을 제공합니다. 아래 Google 연결·계정·팀 공유 설명은 해당 기능이 있는 통합 테스트 버전 등에만 적용됩니다. 기능이 없는 버전에서 해당 정보를 수집하는 것은 아닙니다.

1. 기기에 저장되는 기록과 백업

메모, 할 일, 일정, 반복·기념일과 생년월일, 태그·해시태그, 시간표, 공정률·완료 기록, 목표·프로젝트 및 설정은 기본적으로 사용자의 기기에 저장됩니다. 기본 로컬 기능은 회원가입 없이 사용할 수 있습니다.

백업에는 버전별 백업 대상 기록과 설정, 생성 시각, 운영체제 및 기기 이름 등이 포함될 수 있습니다. 로컬 백업과 내보내기 파일은 사용자가 선택한 위치에 저장되며, 그 위치가 외부 저장장치나 동기화 폴더이면 사본이 외부에 남을 수 있습니다.

2. 선택적 Google 연결과 데이터 사용

  • 계정 정보: Drive 연결 시 계정 식별과 연결 상태 표시를 위해 이메일 및 이메일 확인 정보를 사용합니다. 연결은 Google 로그인 화면에서 승인하며 앱이 Google 비밀번호를 받거나 저장하지 않습니다.
  • 권한 범위: Windows Drive 연결은 openid, email, https://www.googleapis.com/auth/drive.appdata를 요청합니다. Drive 권한은 Allset의 앱 전용 저장 공간을 읽고 쓰는 용도이며 사용자의 일반 Drive 파일 전체에 접근하는 권한이 아닙니다.
  • 백업·복원: 사용자가 요청한 백업을 연결된 Google 계정의 앱 전용 공간에 저장하고, 선택한 백업을 내려받아 복원합니다. 자동 백업은 지원 버전에서 사용자가 켠 경우 동작합니다.
  • 수동 동기화: 사용자가 동기화를 실행하면 호환되는 Windows·Mac·Android 버전 사이에서 지원 항목의 변경 내용을 교환·병합합니다. 동기화 데이터에는 기록 식별자, 변경 시각, 기기 식별자, 변경 순서와 이력 등이 포함될 수 있습니다. 충돌 내용과 기기별 변경 이력은 확인·해결 및 변경 유실 방지를 위해 보관될 수 있습니다. 실시간 공동 편집이나 모든 설정·프로젝트 보드의 동일한 동기화를 보장하지 않습니다.
  • 저장 위치와 보호: Google 백업·동기화 데이터는 사용자가 연결한 Drive의 앱 전용 공간에 저장되며 일반 파일 목록에 보이지 않습니다. 인증 토큰은 연결 유지에 사용됩니다. Windows 버전은 운영체제의 보안 저장 기능으로 암호화해 기기에 저장하며 해당 기능을 사용할 수 없으면 연결 정보 저장을 진행하지 않습니다.

3. Google 데이터 이용 목적과 제한

Google에서 받은 정보는 계정 연결, 사용자가 요청한 백업·복원·수동 동기화를 제공하기 위해 사용합니다. Google 사용자 데이터를 판매하거나 광고 타기팅 또는 범용 AI 모델 학습에 사용하지 않습니다. Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용(Limited Use) 요건을 포함한 Google API Services User Data Policy를 준수합니다.

4. 선택적 계정·구매·팀 공유 기능

해당 기능이 있는 버전에서 Google 계정으로 Allset에 로그인하면 계정 식별과 기능 권한 확인을 위해 인증 서비스 Supabase에서 계정 식별자와 이메일 등 로그인 정보를 처리합니다. 이 로그인은 개인 Drive 연결과 별개이며, 로그인만으로 Drive 전체 접근 권한이 생기지 않습니다. 구매 기능을 사용하는 경우 결제 서비스에서 결제 정보를 처리하고 앱 서버는 주문·계정 식별자와 결제 상태 등 권한 확인에 필요한 정보를 처리합니다.

팀 공유를 선택한 경우 공유 대상으로 지정한 일정과 팀 정보, 이름·직책·회사명·작성자 정보 등이 Supabase에 저장되고 권한이 있는 팀원에게 제공됩니다. 개인 Drive 백업을 팀원에게 자동 공개하는 기능은 아닙니다. 팀 기록의 서버 정리와 로컬 보관 정책은 해당 버전의 안내에 따르며 서버에서 정리해도 이미 내려받은 기기 사본은 남을 수 있습니다.

5. 외부 서비스와 홈페이지

개인 Drive 백업·동기화 기록은 Google로 전송됩니다. 공휴일·음력 자료 갱신 시 GitHub의 공개 자료를 요청할 수 있으며 이 요청에 메모나 일정 본문을 포함하지 않습니다. 홈페이지는 GitHub Pages로 제공되고 별도의 광고 추적·방문 분석 스크립트나 문의 입력 폼을 설치하지 않았습니다. 서비스 제공자는 요청 처리와 보안을 위해 접속 정보를 처리할 수 있으며 해외 서비스를 사용하는 데이터는 국외에서 처리될 수 있습니다.

6. 보관·삭제·연결 해제

  • 로컬 기록과 백업은 사용자의 기기 및 선택한 저장 위치에 보관됩니다. 삭제된 기록은 휴지통, 백업 또는 동기화 이력에 사본이 남을 수 있습니다. 앱 휴지통은 최대 30일 보관 후 정리되며 영구 삭제할 수 있습니다.
  • Google 연결 해제는 기기의 연결 정보를 삭제하고 Google 권한 해제를 시도합니다. 네트워크 오류 등으로 철회가 완료되지 않았다면 Google 계정 연결 관리에서도 권한을 해제할 수 있습니다.
  • 연결 해제는 기존 Drive 백업·동기화 파일을 자동 삭제하지 않습니다. Drive 설정의 앱 관리에서 Allset의 숨겨진 앱 데이터를 삭제할 수 있습니다. 다시 동기화할 기기에 로컬 자료가 남아 있으면 이후 동기화 시 다시 전송될 수 있습니다.
  • 완전히 삭제하려면 각 기기의 로컬 자료, 로컬 백업·내보내기 파일 및 Google 앱 데이터를 각각 확인하세요. 앱 제거만으로 모든 사본이 삭제되지는 않습니다.
  • 개발자는 개인 기기 기록이나 개인 Drive의 숨겨진 앱 데이터를 직접 열람·삭제하는 관리 기능을 제공받지 않습니다. 계정·팀 공유 서버 자료의 삭제 문의는 아래 이메일로 요청할 수 있습니다.

7. 이메일 문의와 변경 안내

문의 이메일을 보내면 이메일 주소, 문의 내용 및 첨부 자료를 받아 답변과 문제 해결에 사용합니다. 비밀번호·인증 토큰이나 불필요한 전체 백업 파일을 보내지 마세요. 문의 자료 삭제는 같은 이메일로 요청할 수 있습니다.
