자주 묻는 질문

모바일에서도 사용할 수 있나요?

Android 버전은 공개 출시 준비 중입니다. 다운로드 주소가 준비되면 공식 홈페이지에서 안내합니다.

PC와 모바일 연동 비용은 얼마인가요?

연동 기능은 1회 2,900원으로 안내하며 정기 구독이 아닙니다. 지원 버전에서 같은 Allset 계정과 Google 계정으로 연결한 후 양쪽의 동기화 버튼을 눌러 기록을 주고받습니다. 현재 Store 무료판에는 연동 기능이 포함되지 않습니다.

앱의 모바일 안내 광고를 없애려면?

연동 이용권 구매 권한이 확인되면 메인창 안내와 예약 팝업이 사라집니다. 구매 복원으로 권한을 확인한 경우도 같습니다. 미구매 사용자의 예약 안내는 앱이 켜져 있을 때 오전 9:05, 낮 12:05, 오후 4:05에 표시되며 놓친 안내를 몰아서 표시하지 않습니다.

어디서 다운로드할 수 있나요?

Windows 무료판 1.0.2는 Microsoft Store에서 다운로드할 수 있습니다.

회원가입이나 결제가 필요한가요?

Windows 무료판은 회원가입과 결제 없이 사용할 수 있습니다. 홈페이지에는 현재 무료판과 출시 준비 중인 모바일·연동 기능을 구분해 안내합니다. Google Drive 백업·기기 간 동기화, Excel 내보내기, 팀 공유는 1.0.2 무료판에 포함되지 않습니다.

반복일정이 할일 목록에 보이지 않아요.

설정 → 표시 설정에서 반복일정·기념일 표기 설정을 확인하세요. 기본은 당일 표시입니다. 캘린더 날짜 칸과 날짜별 일정 목록에는 미래 일정도 표시됩니다.

다른 컴퓨터로 기록을 옮기려면?

설정 → 로컬 백업에서 지금 백업을 누르고 파일을 보관하세요. 다른 컴퓨터에서 파일 복원으로 불러올 수 있습니다. 복원 전 현재 기록도 백업하세요.

입력 방법을 어디서 확인하나요?

제목 옆이나 입력 버튼 옆의 작은 (?) 버튼을 누르세요. 날짜·반복일정·기념일·학기 시간표 입력 예시를 주제별로 볼 수 있습니다.

Mac에서도 사용할 수 있나요?

이번 무료 배포판은 Windows용입니다. 다른 운영체제 지원은 준비가 완료되면 별도로 안내하겠습니다.
