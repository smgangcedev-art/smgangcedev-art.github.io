자주 묻는 질문

1.0.9 업데이트는 언제 받을 수 있나요?

2026년 10월 27일 Microsoft Store에 제출했으며 현재 심사 중입니다. 아직 배포되지 않았고, 현재 공개 버전은 1.0.8입니다. 승인·게시 후 Store 라이브러리에서 업데이트할 수 있습니다.

공정률 단계별 메모, 텍스트·CSV·클립보드 선택 내보내기, 프로젝트 그룹 선택과 캘린더 드래그 개선이 포함됩니다. Google 로그인·연동, 팀 공유, 유료 결제·광고, Excel 내보내기는 포함되지 않습니다.

1.0.6 업데이트는 언제 받을 수 있나요?

현재 공개 버전은 1.0.5입니다. 1.0.6은 2026년 10월 21일 Microsoft Store에 제출했으며 현재 심사 중으로, 승인·게시 후 업데이트할 수 있습니다.

제목줄·해시태그 고정, 슬림한 메인바, 비밀번호 설정 팝업, 프로젝트 종료일, 창 안의 뽀모도로, 창 자석 정렬 등을 반영했습니다. Google 연동·공유·팀 기능·Excel·광고는 포함하지 않습니다.

모바일에서도 사용할 수 있나요?

Android 버전은 공개 출시 준비 중입니다. 다운로드 주소가 준비되면 공식 홈페이지에서 안내합니다.

PC와 모바일 연동 비용은 얼마인가요?

연동 기능은 1회 2,900원으로 안내하며 정기 구독이 아닙니다. 지원 버전에서 같은 Allset 계정과 Google 계정으로 연결한 후 양쪽의 동기화 버튼을 눌러 기록을 주고받습니다. 현재 Store 무료판에는 연동 기능이 포함되지 않습니다.

Store 앱에 광고나 유료 연동이 있나요?

Store 무료판에는 광고·예약 광고 팝업·Google 연동·팀 공유·Excel 내보내기가 포함되지 않습니다. 회원가입이나 광고 제거 결제가 필요하지 않습니다. 모바일과 기기 간 연동은 별도로 준비 중인 지원 버전의 기능입니다.

어디서 다운로드할 수 있나요?

Windows 무료판은 Microsoft Store에서 다운로드할 수 있습니다.

회원가입이나 결제가 필요한가요?

Windows 무료판은 회원가입과 결제 없이 사용할 수 있습니다. 홈페이지에는 현재 무료판과 출시 준비 중인 모바일·연동 기능을 구분해 안내합니다. 1.0.3 업데이트에는 프로젝트·목표·여러 시각 알림을 포함하며 Google 연동·팀 공유·Excel 내보내기·광고는 제외합니다. 1.0.3은 Microsoft Store에 출시되었습니다. 기존 사용자는 Microsoft Store 라이브러리에서 업데이트를 확인해 주세요.

반복일정이 할일 목록에 보이지 않아요.

설정 → 표시 설정에서 반복일정·기념일 표기 설정을 확인하세요. 기본은 당일 표시입니다. 캘린더 날짜 칸과 날짜별 일정 목록에는 미래 일정도 표시됩니다.

다른 컴퓨터로 기록을 옮기려면?

설정 → 로컬 백업에서 지금 백업을 누르고 파일을 보관하세요. 다른 컴퓨터에서 파일 복원으로 불러올 수 있습니다. 복원 전 현재 기록도 백업하세요.

입력 방법을 어디서 확인하나요?

제목 옆이나 입력 버튼 옆의 작은 (?) 버튼을 누르세요. 날짜·반복일정·기념일·학기 시간표 입력 예시를 주제별로 볼 수 있습니다.

Mac에서도 사용할 수 있나요?

이번 무료 배포판은 Windows용입니다. 다른 운영체제 지원은 준비가 완료되면 별도로 안내하겠습니다.
