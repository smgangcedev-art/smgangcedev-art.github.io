Windows 2.0.7 업데이트

  • 시험 자료에서 PDF와 PPT를 여러 탭으로 열고 본문을 검색할 수 있습니다. 텍스트 PDF에서 복사한 내용을 코드 편집기에 붙여넣을 수 있습니다. PPT 열기에는 Windows용 PowerPoint가 필요합니다.
  • 교수자가 공개한 답안을 학생 화면에서 확인합니다. 수업관리에서는 제출 확인 대기 학생을 먼저 보고, 학생별로 종료를 허용하고 진단 로그를 받을 수 있습니다.
  • Microsoft Store 설치 경로에서 C++ 컴파일과 링크가 실패하던 문제를 수정했습니다.

Windows용 C++ 실습·과제·시험 앱입니다. Microsoft Store에서 Windows 버전을 설치할 수 있습니다. 교수자 서비스는 C++ 앱에서 별도 승인이 필요합니다. Java·AI 앱의 승인은 C++에 자동 적용되지 않습니다.

GCC 내장 · C++ 콘솔 실행 · 출력 비교 자동채점 · 교수자 확인 채점 · 20초 간격 암호화 백업 · 교수자 승인 복구를 지원합니다.

시험 모드에서는 창 이동 제한과 보조 모니터 가림이 적용됩니다. 과제 모드와 구분해 이용하세요.

코드빚다 C++ Mac 설치 방법

전체 Xcode 앱은 필요하지 않습니다. C++ 컴파일에는 Apple Command Line Tools를 사용하며, 이미 준비된 Mac은 설치 단계를 건너뜁니다.

  1. 위의 C++ Mac DMG를 다운로드하고 엽니다.
  2. DMG 안의 코드빚다-C++.app을 실행합니다. 보안 경고가 나오면 아래 안내를 확인하세요.
  3. 코드빚다 C++ 환경설정에서 설치 시작을 눌러 앱을 응용 프로그램 폴더에 설치합니다.
  4. 실행 도구가 없으면 Apple 실행 도구 설치를 누르고 Apple 설치창에서 설치를 완료합니다. 이 과정에는 인터넷 연결이 필요할 수 있습니다.
  5. 설치 완료 여부 확인을 눌러 C++ 실행 점검이 끝나면 앱 실행을 누릅니다.
  6. 이후에는 응용 프로그램 폴더에서 코드빚다-C++을 실행합니다. 설치 디스크는 추출해도 됩니다.

학생은 Google 로그인 없이 과제·시험에 참여합니다. 교수·조교·마스터는 앱에서 Google 로그인을 사용합니다.

Mac 2.0.7 · 시험 자료 탭과 교수자 공개 답안

PDF와 PowerPoint 자료를 탭으로 열고 ⌘F로 원하는 페이지나 슬라이드를 찾으세요. PDF 글자를 드래그해 ⌘C로 복사한 뒤 내 코드의 C++ 편집기에 ⌘V로 붙여넣을 수 있습니다. 이미지로 스캔한 페이지는 텍스트 검색·복사를 지원하지 않습니다.

PPT·PPTX는 Mac 기본 미리보기로 엽니다. 열리지 않는 자료는 PDF로 저장해 열어 주세요.

수업 코드와 학번으로 입장하면 왼쪽 위에 명단에 등록된 이름이 표시됩니다. 교수자가 문항 답안을 공개하면 답안 코드 탭에서 확인할 수 있습니다.

교수자·조교는 제출 확인 대기 학생을 먼저 보고 이름·학번순으로 정렬하거나 학생별로 종료를 허용할 수 있습니다. 담당 교수자는 수업관리에서 진단 로그를 내려받을 수 있습니다. 외부 창 감지는 로그에 기록하며 감지만으로 시험이 잠기지 않습니다.

Mac 2.0.6 · 이론 결과 HTML 및 방 관리

이론 제출 결과를 JSON과 HTML로 저장합니다. 코딩 결과는 소스 파일·노트북·출력 이미지를 유지하며 이론 문항에는 빈 코드 파일을 만들지 않습니다.

교수자 최종 결과에서 학생 답안·점수와 정답·인정답안·채점기준을 함께 확인할 수 있습니다. 학생 배포 자료에는 정답을 노출하지 않습니다.

교수자 본인의 종료·보관된 방을 이름 확인 후 삭제할 수 있습니다. Drive 파일과 수업·수강생 명단은 보존됩니다.

Mac 2.0.6 · 실행 경로와 종료 처리 개선

긴 한글·공백 임시 경로에서 컴파일·실행이 실패하는 문제를 개선했습니다. Java·C++·AI는 짧은 전용 실행 폴더를 사용하며 원본 답안과 백업은 유지합니다.

제출 확인 대기와 교수자·조교의 종료 처리 흐름을 개선했습니다. 설치 안내에 따라 응용 프로그램 폴더에 설치해 주세요.

Mac 2.0.6 · 이론문제와 전체 답안 저장

단일선택·복수선택·단답식·주관식·서술형 이론문제를 첫 페이지에 모아 풀고, 이어서 코딩 문제를 해결할 수 있습니다. 시험·과제의 단일선택·복수선택·단답식은 서버에서 자동 채점하며, 주관식·서술형은 추후 채점합니다.

저장 버튼 또는 ⌘S로 모든 페이지의 이론 답안과 코드를 함께 저장합니다. 시험·과제에서는 암호화 백업을 사용하고, 공부모드에서는 학습 JSON을 저장해 다시 열면 이어서 풀 수 있습니다. 공백·줄바꿈·한글·외국어 원문을 보존합니다.

최종 제출 후에는 답안이 잠기며, 연결이 끊겨도 확정된 내용을 재전송합니다. 교수자·소속 조교의 제출 확인 후 종료할 수 있습니다.

Mac 2.0.6 수업 진행 안내

교수자는 시험 시작 전에 해당 수업의 XLSX 또는 UTF-8 CSV 명단을 등록하세요. 학번은 앞자리 0을 포함한 텍스트로 저장합니다. 소속 조교도 같은 명단을 조회하며, 교체는 교수자만 할 수 있습니다. 학생은 학번으로 참여하므로 이름 표기가 달라도 차단하지 않습니다.

최종 제출하면 답안과 실행 결과가 고정됩니다. 전송 실패 시 대기 상태를 유지하고 같은 내용을 재전송하므로 앱을 열어 두세요. 서버 저장 후에도 교수자 또는 소속 조교의 제출 확인을 기다린 다음 활성화된 종료 버튼을 누릅니다.

교수자·소속 조교는 학생 현황 조회, 백업 복구 승인, 개별·전체 과제 전환을 할 수 있습니다. 이미 제출한 답안은 다시 열리지 않으며 각 앱의 계정 권한과 학생 데이터는 분리됩니다.

2.0.1부터 자동 업데이트를 지원합니다.

2.0.0 사용자는 2.0.7을 한 번 직접 설치하세요. 2.0.1~2.0.6 사용자는 메인화면에서 이번 업데이트를 자동으로 내려받습니다.

작업을 저장·제출한 뒤 메인화면의 업데이트 및 재시작 / Update & restart을 누르면 앱을 교체하고 다시 엽니다. 시험·과제·출제 중에는 자동으로 재시작하지 않습니다.

업데이트 파일의 전자서명과 무결성을 확인하며, 새 앱이 정상 시작하지 못하면 이전 앱으로 복구를 시도합니다. 쓰기 권한이나 macOS 보안 확인 때문에 자동 설치가 실패하면 위 DMG로 직접 설치하세요.

첫 실행 시 보안 경고가 표시될 수 있습니다.

현재 Mac 2.0.7는 임시 서명 배포본이며 Apple 공증은 포함되지 않습니다. 이 홈페이지에서 받은 코드빚다-C++ 앱인지 확인하고 아래 안내를 따라 주세요.

개발자를 확인할 수 없거나 Apple에서 확인할 수 없다고 나와요.

코드빚다-C++ 실행을 한 번 시도한 뒤 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기를 확인하세요. 열려는 앱 이름이 코드빚다-C++인지 확인합니다. 학교에서 관리하는 Mac에서 허용할 수 없다면 담당 관리자에게 문의하세요.

Apple의 Mac 앱 열기 안내 ↗

앱이 손상되었다는 메시지가 나와요.

다운로드와 앱 복사가 끝났는지 확인하고, 위의 C++ Mac DMG를 다시 다운로드하여 설치해 주세요. 그래도 같은 메시지가 나오면 오류 화면과 macOS 버전을 담당 교강사에게 전달해 주세요.
