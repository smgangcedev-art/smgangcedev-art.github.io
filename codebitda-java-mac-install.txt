코드빚다-JAVA 2.0.4 — Mac 설치 안내
대상: macOS 13 이상, Apple Silicon(M1 이후). Intel Mac 미지원.

JDK가 앱에 포함되어 있습니다. Java나 JDK를 따로 설치하거나 경로를 설정할 필요가 없습니다.

1. 위의 Java Mac DMG를 다운로드하고 엽니다.
2. 코드빚다-JAVA.app을 DMG 안의 Applications(응용 프로그램) 폴더로 드래그합니다.
3. 복사가 끝나면 Finder의 응용 프로그램 폴더에서 코드빚다-JAVA를 실행합니다. 보안 경고가 나오면 아래 안내를 확인하세요.
4. 앱이 열리면 담당 교강사의 안내에 따라 과제 시작 또는 시험 응시를 선택합니다. 설치 디스크는 추출해도 됩니다.

보안 경고 안내
현재 임시 서명 배포본이며 Apple 공증은 포함되지 않습니다.
이 홈페이지에서 받은 코드빚다-JAVA 앱인지 확인하고 실행을 한 번 시도한 뒤, 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기를 확인하세요.
학교에서 관리하는 Mac은 담당 관리자에게 문의하세요.
손상 메시지가 계속되면 다시 다운로드·설치한 뒤, 오류 화면과 macOS 버전을 담당 교강사에게 전달해 주세요.

다운로드 및 자세한 안내: https://codepretender.com/codebitda-java.html#mac-downloads
Apple 안내: https://support.apple.com/ko-kr/102445

자동 업데이트
2.0.0 사용자는 2.0.4를 한 번 직접 설치하세요. 2.0.1·2.0.2·2.0.3 사용자는 메인화면에서 이번 업데이트를 자동 다운로드합니다.
작업을 저장·제출한 뒤 메인화면의 ‘업데이트 및 재시작’을 누르세요. 시험·과제·출제 중에는 자동으로 재시작하지 않습니다.
파일의 전자서명과 무결성을 검증하고 새 앱의 시작에 실패하면 이전 앱으로 복구를 시도합니다.
본인 계정으로 응용 프로그램에 설치하세요. 권한 또는 보안 확인으로 실패하면 홈페이지 DMG로 직접 설치하세요.

2.0.4 수업 진행 안내
- 교수자는 Google 로그인 후 ‘수업 현황 · 제출 확인’에서 해당 시험의 XLSX 또는 UTF-8 CSV 명단을 등록하세요. 학번은 텍스트로 저장하세요.
- 명단은 시험별로 서버에 보관되며 소속 조교도 조회할 수 있습니다. 명단 교체는 교수자만 할 수 있습니다.
- 학생은 명단의 학번으로 참여합니다. 입력 이름이 명단과 달라도 학번으로 확인합니다.
- 최종 제출 후 답안은 고정됩니다. 연결 실패 시 앱에서 전송을 재시도하며 앱을 강제 종료하지 마세요.
- 서버 저장 뒤에도 교수자 또는 소속 조교가 제출 확인을 할 때까지 기다린 다음 활성화된 종료 버튼을 누르세요.
- 교수자·조교는 학생 현황에서 개별 또는 전체 선택으로 과제 전환·제출 확인을 할 수 있습니다. 제출한 답안은 다시 열리지 않습니다.
- 기존 자동 백업 암호화와 승인에 의한 복구를 유지합니다. 최종 제출물에 새 전자서명·추가 암호화를 적용하지 않습니다.

2.0.4: 이론문제 5종을 지원합니다. 저장 버튼 또는 ⌘S로 모든 이론·코딩 답안을 저장하세요. 공부모드는 학습 JSON을 저장하고 다시 열어 이어서 풀 수 있습니다.
