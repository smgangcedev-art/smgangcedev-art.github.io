실제 앱 화면

One app, different ways

누구에게 보내든,
목적에 맞는 시작.

하나의 앱에서 사용 용도를 선택합니다. 용도별 기본 문구를 적용하고 제목과 본문을 자유롭게 수정할 수 있습니다.

선생님·교수 → 학생

수업 자료, 과제 안내, 학생별 결과 자료를 학번이나 이름으로 연결합니다.

업체 → 고객

고객별 서비스 안내, 계약 관련 자료와 견적서를 전달합니다.

개인 → 고객

프리랜서의 작업 결과물, 프로젝트 안내와 개별 자료를 보냅니다.

단체·행사 → 회원

회원 공지, 참가 안내와 행사 자료를 대상자별로 준비합니다.

요금·회비 청구

청구금액, 납부기한, 청구월과 납부안내를 넣어 메일을 작성합니다. 결제·자동이체 기능은 포함하지 않습니다.

직접 작성

내 업무에 맞게 제목과 본문을 만들고 필요한 수신자만 선택합니다.

Check, personalize, send

발송 전에 확인할 수 있도록.

01 / IMPORT

Excel 명단 그대로

XLS, XLSX, CSV를 불러오고 수신자 정보를 확인합니다. 명단에 없는 수신자를 추가하거나 불필요한 항목을 제외할 수 있습니다.

02 / ATTACH

개인별 첨부파일

관리번호·학번 또는 이름으로 파일을 연결합니다. 여러 첨부파일과 경로 복사·붙여넣기를 지원합니다.

03 / COMPOSE

수신자에 맞는 문구

제목·본문을 수정하고 이름·안내항목 등을 자동으로 채웁니다. 발송 이메일과 답장받을 주소를 따로 지정할 수 있습니다.

04 / SELECT

체크해서 선택 발송

한 명, 선택한 여러 명, 전체 발송을 구분합니다. 먼저 내 메일로 1통 테스트해 내용을 확인하세요.

05 / SCHEDULE

예약·매월 반복

지정한 시각이나 매월 같은 날짜에 발송하도록 예약합니다. 청구월·납부기한 자동 변경을 선택할 수 있습니다.

06 / TRACK

진행 상황과 기록

진행률과 완료 알림을 확인합니다. 메일 설정을 저장하고 선택한 경우 앱 비밀번호를 이 Windows 계정에 암호화해 기억합니다.

이용 전에 확인하세요

발송에는 본인의 SMTP 사용 가능한 메일 계정이 필요합니다. Gmail은 계정에 따라 2단계 인증과 앱 비밀번호가 필요합니다. 예약 시각에는 PC와 앱이 켜져 있고 인터넷에 연결되어 있어야 합니다. 메일 제공업체의 발송 한도가 적용됩니다.

예약에 저장된 수신자·본문·첨부파일 사본은 원본을 수정해도 바뀌지 않습니다. 반복 청구의 날짜 변경 옵션은 메일 문구에 적용되며 첨부파일 안의 날짜·금액을 수정하지 않습니다.
