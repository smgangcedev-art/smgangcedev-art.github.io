How to install Codebitda AI on Mac

Python 3.11, TensorFlow, NumPy, and Matplotlib are included in the app. You do not need to install Python or Anaconda separately.

These instructions are in English. App buttons may still appear in Korean; the original labels are shown below where needed.

  1. Download the AI Mac DMG above and open it.
  2. Drag 코드빚다-AI.app to the Applications folder inside the DMG.
  3. When copying is complete, open 코드빚다-AI from Applications in Finder. If a security warning appears, see the guidance below.
  4. The first code run may take a little longer while Python and TensorFlow initialize. Please wait.
  5. Once the app opens, select the assignment or exam option as instructed by your instructor. You can eject the installation disk.

Students can take assignments and exams without signing in to Google. Instructors, teaching assistants, and the master administrator use Google sign-in in the app.

What’s new in Mac 2.0.3

Practice freely in Study mode, or join assignments and exams with a class code and student number. Canceling entry restores the previous screen. Students with no response for over 90 seconds are shown as disconnected.

Queued submissions retain the same answers after a connection failure. Duplicate submissions and lost exit responses are handled more reliably. Local ZIP backup errors remain visible separately from server storage status.

Mac 2.0.3 classroom workflow

Before an exam, the instructor registers an XLSX or UTF-8 CSV roster for that exam. Keep student numbers as text, including leading zeros. Assistants share the roster; only the instructor can replace it. Students join by student number, even when their name spelling differs.

Submitting locks the answers and results. If upload fails, the app keeps the submission pending and retries the same content. Keep the app open. After server storage succeeds, wait for the instructor or their assistant to confirm the submission, then use the enabled Exit button.

Instructors and their assistants can view student status, approve backup recovery, and switch selected or all active exams to assignment mode. Submitted answers remain locked. Accounts and student data remain separate for each app.

Automatic updates start with 2.0.1.

If you use 2.0.0, install 2.0.3 manually once. Versions 2.0.1 and 2.0.2 download this update automatically from the home screen.

After saving or submitting your work, return to the home screen and choose 업데이트 및 재시작 / Update & restart to replace and reopen the app. It will not restart automatically during exams, assignments, or authoring.

Update signatures and file integrity are verified. If the new app fails to start, the updater attempts to restore the previous app. If permissions or macOS security prevent installation, install the DMG above manually.

A security warning may appear the first time you open the app.

Mac 2.0.3 is ad-hoc signed and is not notarized by Apple. Make sure you downloaded 코드빚다-AI from this website, then follow the instructions below.

macOS says the developer cannot be verified or Apple cannot verify this app.

Try opening 코드빚다-AI once, then check System Settings → Privacy & Security → Open Anyway. Make sure the app name matches 코드빚다-AI. On a school-managed Mac, contact your administrator if you cannot allow it.

Apple’s guide to opening Mac apps ↗

macOS says the app is damaged.

Make sure the download and app copy are complete. Download the AI Mac DMG above again and reinstall. If the message persists, send a screenshot of the error and your macOS version to your instructor.
