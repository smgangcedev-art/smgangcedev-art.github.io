Allset 개인정보처리방침

시행일 2026년 11월 1일

로컬 기록

할 일·메모·반복 일정·기념일·생년월일·태그·시간표·완료 기록과 설정은 기본적으로 사용자의 기기에 저장됩니다. 기본 기능은 로그인 없이 사용할 수 있습니다. 파일 백업은 사용자가 선택한 위치에 저장됩니다.

Allset 계정과 데이터 공유

Google 로그인을 선택하면 Allset 계정 인증을 위해 이메일·Google 제공 계정 식별 정보와 이메일 인증 상태를 처리합니다. 계정은 Supabase 인증 서비스와 권한 저장소를 사용합니다. 데이터 공유 구매 권한은 Allset 사용자 ID에 연결되어 같은 계정의 앱에서 함께 확인됩니다. 앱은 Google 비밀번호를 받지 않습니다. Android 인증 토큰은 Android Keystore를 이용해 암호화된 앱 전용 저장소에 보관합니다.

Google Drive 연동

데이터 공유 사용자가 연결을 선택하면 Google Drive 앱 전용 저장 공간(drive.appdata)에 앱 기록과 동기화 변경 기록을 전송합니다. Google Drive 일반 파일 전체를 읽는 권한을 요청하지 않습니다. 실제 변경 반영은 수동 동기화로 수행하며 자동 확인은 원격 상태 읽기·비교만 합니다. Allset 로그인 계정과 Drive 연결은 별도이며 사용할 Drive 계정은 Google 승인 화면에서 확인할 수 있습니다.

웹 결제와 구매 권한

결제는 Merchant of Record인 Polar에서 처리합니다. Android 앱에는 구매 기능·결제 링크가 없고 구매 권한만 확인합니다. 결제 서비스가 처리하는 결제수단 정보는 앱이 직접 수집·저장하지 않습니다. 운영 서버는 Allset 사용자 ID, 확인된 주문 ID·상품·결제 및 환불 상태·확인 시각을 구매 권한 부여와 환불 반영, 중복·부정 사용 방지 목적으로 처리합니다. 테스트 주문은 정식 권한을 부여하지 않습니다.

외부 서비스와 보안

인증·권한 확인에는 Google 및 Supabase, 웹 결제에는 Polar를 사용합니다. 서비스 요청 처리 과정에서 해당 사업자가 IP·접속 기록 등을 처리할 수 있습니다. 웹사이트는 GitHub Pages와 Cloudflare를 통해 제공합니다. 네트워크 통신은 HTTPS를 사용합니다. Google 사용자 데이터를 판매하거나 광고 타기팅·범용 AI 학습에 사용하지 않으며 Google API 사용자 데이터 정책의 제한적 사용 요건을 준수합니다.

삭제 및 보관

앱 설정의 Allset 계정 화면에서 삭제 요청 또는 별도의 계정 삭제 웹페이지에서 계정 및 연결 데이터 삭제를 요청할 수 있습니다. 로그인할 수 없다면 지원 이메일로 요청하세요. 등록 이메일로 요청 확인·처리 안내를 제공합니다. 계정·인증 토큰·권한·서버 연결 정보는 삭제 대상이며 법정 보관 또는 보안상 보관이 필요한 결제 정보는 별도 사유·기간을 안내합니다. 기기 일정, 개인 Drive 파일, 내보낸 파일은 자동 삭제되지 않으며 사용자가 직접 정리할 수 있습니다. 계정 삭제는 결제 환불과 별도입니다.

Google 권한은 Google 계정의 연결 관리에서 철회할 수 있습니다. Drive 앱 전용 자료는 Drive 설정의 앱 관리에서 별도로 삭제할 수 있습니다. 앱의 로컬 로그아웃은 현재 기기의 로그인 정보만 지우고 일정을 유지합니다.
