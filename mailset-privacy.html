개인정보처리방침

대상: MailSet Windows 앱 · 게시일: 2026년 10월 24일
개발자: codepretender · 문의: codepretender.dev@gmail.com

현재 출시 준비 버전의 동작을 기준으로 안내합니다. MailSet은 사용자 PC에서 명단과 메일을 준비하고 사용자가 지정한 메일 서버로 전송하는 프로그램입니다.

앱에서 사용하는 정보

사용자가 불러오거나 입력한 이름, 관리번호·학번, 이메일, 안내항목, 청구정보, 메일 제목·본문, 첨부파일과 메일 계정 설정을 사용합니다. 명단 확인, 개인별 메일 작성, SMTP 발송, 중복 발송 방지 및 예약 실행에 필요한 범위에서 처리합니다.

로컬 저장과 보호

메일 설정과 발송 기록은 사용자 PC에 저장됩니다. 발송 기록에는 수신자 정보, 발송 시각·상태 및 중복 확인용 값 등이 포함될 수 있습니다. 예약에는 수신자·본문·첨부파일의 사본이 저장됩니다.

비밀번호 기억을 선택한 경우 앱 비밀번호는 Windows DPAPI로 암호화합니다. 예약 목록도 같은 방식으로 보호합니다. 일반 설정과 발송 기록 전체가 암호화되는 것은 아니므로 Windows 계정과 PC 접근 권한을 관리해 주세요.

외부 전송

메일을 발송하면 선택한 메일 제공업체의 SMTP 서버에 인증 정보와 수신자, 메일 내용 및 첨부파일이 전달됩니다. 제공업체와 수신자의 메일 시스템에도 데이터가 보관될 수 있으며 각 서비스의 정책이 적용됩니다. Reply-To를 지정하면 답장 주소가 메일 헤더에 포함됩니다.

앱은 개발자 서버로 명단, 메일 본문, 첨부파일 또는 앱 비밀번호를 수집·전송하지 않으며 광고·사용 분석을 위한 추적 기능을 포함하지 않습니다. 사용자가 지원 문의로 직접 보낸 내용은 이메일 서비스에 보관되며 문의 대응에 사용합니다.

보관과 삭제

로컬 설정·발송 기록·예약 데이터는 사용자가 삭제할 때까지 남을 수 있습니다. 예약 취소는 발송을 중단하는 동작이며 사본 삭제와는 다릅니다. 삭제하려면 먼저 예약을 취소하고 앱을 종료한 후 데이터 폴더를 확인하세요.

일반 실행 버전의 데이터 폴더는 %LOCALAPPDATA%\AutoMailSendingApp입니다. 이 폴더명은 이전 버전과의 데이터 호환을 위해 유지됩니다. Store 설치 버전에서는 Windows의 앱 데이터 격리 정책에 따라 실제 위치가 달라질 수 있습니다. 데이터 삭제는 저장된 설정·예약과 중복 발송 방지 기록도 지우므로 필요한 기록을 먼저 보관하세요. 원본 Excel과 첨부파일, 이미 보낸 메일은 별도로 관리해야 합니다.

문의 메일에 포함한 개인정보의 열람·정정·삭제를 요청하려면 지원 이메일로 연락해 주세요. 개발자는 사용자 PC의 로컬 데이터나 메일 계정에 직접 접근할 수 없습니다.

변경 안내

처리 방식이 변경되면 이 페이지의 내용과 게시일을 갱신합니다.
